# MesclaInvest

Projeto desenvolvido para a disciplina **Projeto Integrador 3** do curso de **Engenharia de Software da PUC-Campinas (2026)**.

O sistema consiste em um aplicativo mobile que simula uma plataforma digital de investimentos em startups vinculadas ao ecossistema de inovação **Mescla**. A aplicação permite que usuários explorem projetos, acompanhem informações empresariais e realizem negociações simuladas de tokens representando participação nesses projetos.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

 # 1) Objetivo do Projeto

O objetivo do MesclaInvest é simular um ambiente digital de investimento em startups, promovendo maior integração entre universidade, estudantes e possíveis investidores.

A plataforma permite visualizar startups, acompanhar suas informações e negociar tokens simulados que representam participação nos projetos.

O foco do projeto está no desenvolvimento da arquitetura de software, integração entre backend e aplicativo mobile, e implementação das funcionalidades propostas.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

# 2) Funcionalidades do Sistema

- Cadastro e autenticação de usuários
- Recuperação de senha
- Catálogo de startups
- Visualização de informações institucionais das startups
- Consulta de estrutura societária e capital investido
- Sistema de perguntas aos empreendedores
- Balcão de negociação simulada de tokens
- Carteira virtual com saldo fictício
- Compra e venda simulada de tokens
- Dashboard com variação de valor dos tokens
- Sistema opcional de autenticação multifator (2FA)
